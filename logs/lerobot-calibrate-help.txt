                        J1 - Shoulder pan (DM8009) J2 - Shoulder lift (DM8009)
                        J3 - Shoulder rotation (DM4340) J4 - Elbow flex
                        (DM4340) J5 - Wrist roll (DM4310) J6 - Wrist pitch
                        (DM4310) J7 - Wrist rotation (DM4310) J8 - Gripper
                        (DM4310) Torque mode settings for manual control When
                        enabled, motors have torque disabled for manual
                        movement (default: True)

                        When True, expose `.vel` and `.torque` per motor in
                        action features. Default False for compatibility with
                        the position-only openarm_mini teleoperator. (default:

RebotArm102LeaderConfig ['teleop.left_arm_config']:
  Base configuration class for the Seeed Studio StarArm102 / reBot Arm 102 leader.
  
      The reBot Arm 102 is a 7-joint (incl. gripper) leader arm driven by FashionStar
      UART smart servos. Servo communication goes through ``motorbridge-smart-servo``.
      

  --teleop.left_arm_config.port str
                        USB-to-UART device the leader arm is connected to
                        (e.g. "/dev/ttyUSB0"). (default: None)
  --teleop.left_arm_config.baudrate int
  --teleop.left_arm_config.joint_ids dict[str,int]
                        Servo id of each joint on the UART bus. (default:
                        {'shoulder_pan': 0, 'shoulder_lift': 1, 'elbow_flex':
                        2, 'wrist_flex': 3, 'wrist_yaw': 4, 'wrist_roll': 5,
                        'gripper': 6})
  --teleop.left_arm_config.joint_directions dict[str,int]
                        Per-joint sign applied to raw servo angles so the
                        leader matches the follower convention. The gripper
                        additionally carries a scale (e.g. -6) to widen its
                        range to the reBot B601 follower's gripper travel.
                        (default: {'shoulder_pan': -1, 'shoulder_lift': -1,
                        'elbow_flex': 1, 'wrist_flex': 1, 'wrist_yaw': 1,
                        'wrist_roll': -1, 'gripper': -6})
  --teleop.left_arm_config.joint_ranges dict[str,list[int]]
                        Per-joint [min, max] output range in degrees. Matches
                        the reBot B601 follower joint limits so leader actions
                        can drive the follower key-for-key. (default:
                        {'shoulder_pan': [-150, 150], 'shoulder_lift': [-200,
                        1], 'elbow_flex': [-200, 1], 'wrist_flex': [-80, 90],
                        'wrist_yaw': [-90, 90], 'wrist_roll': [-90, 90],

                        the steady-state read cost is unchanged. (default: 2)
